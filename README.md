## 📄 网页自动刷新 Pro

> 每隔一段时间自动刷新网页，支持「网站范围」与「精准网址」两级规则、自定义刷新间隔、统一设置管理、Mini Timer、倒计时、暂停/重置、可拖拽控制面板与位置记忆。默认不启用，按需配置。

---

### 🚀 功能特点

* ✅ **统一设置 / 管理入口**：油猴菜单与页面控制面板统一打开同一个管理浮层，设置、停用、删除规则集中处理 (v1.3.1)
* ✅ **Mini Timer 自动折叠**：控制面板闲置 5 秒后自动收起为精简倒计时，悬浮、点击、聚焦或操作时恢复完整面板 (v1.3.1)
* ✅ **上下文管理操作**：仅在需要时显示「停用当前页面」「删除网站范围规则」，危险操作均需二次确认 (v1.3.1)
* ✅ **自定义设置浮层**：替代旧版 `prompt / confirm` 主流程，支持行内校验、高频刷新确认与精准规则覆盖提示 (v1.3.1)
* ✅ **网站范围 + 精准网址两级规则**：网站规则作为默认值，精准网址规则优先覆盖 (v1.3)
* ✅ **当前页面可单独停用**：即使网站范围规则仍启用，也可仅排除当前页面，不影响同站其他页面 (v1.3)
* ✅ **绝对时间 deadline 计时**：修复旧版倒计时少 1 秒的问题，并降低后台标签页计时漂移 (v1.3)
* ✅ **支持 1 秒起的整数刷新间隔**：1–4 秒会明确提示高频刷新风险 (v1.3)
* ✅ **旧配置自动迁移**：兼容 v1.1 / v1.2 的 `urlRefreshMap`，迁移后仍保留旧数据 (v1.3)
* ✅ **Shadow DOM 样式隔离与边界保护**：降低站点 CSS 干扰，并在窗口缩放后避免面板跑出可视区域 (v1.3)
* ✅ **右下角控制面板支持拖拽**，并会记住面板位置 (v1.2)
* ✅ 可手动暂停 / 继续刷新，并可一键重置倒计时
* ✅ 浏览器标题栏同步显示倒计时
* ✅ 所有设置持久保存，不用每次刷新都重新配置
* ✅ **默认不开启刷新**，仅在你主动设置后才运行

### 🧩 使用方法

#### 第一步：安装脚本

1. 点击页面上的【安装此脚本】按钮
2. 在需要自动刷新的网页中，点击浏览器右上角的油猴图标，找到本脚本

#### 第二步：打开设置 / 管理

通过任一入口打开同一个设置浮层：

* 油猴菜单：「⚙ 设置 / 管理自动刷新」
* 页面控制面板：「⚙ 设置」

在设置浮层中：

* 输入刷新间隔，例如 `60`，表示每 60 秒刷新一次
* 选择「精准网址」或「网站范围」
* 点击「保存设置」后自动应用

作用范围说明：

* **精准网址**：仅当前完整 URL 生效，优先级最高
* **网站范围**：当前域名下页面默认使用此规则

如果当前页面已经存在精准规则，同时设置网站范围规则，浮层会明确询问是否保留精准覆盖，避免误删。

#### 第三步：停用或删除规则

管理浮层会根据当前状态按需显示：

* 「停用当前页面」：只停止当前页面；若存在网站范围规则，同站其他页面继续生效
* 「删除网站范围规则」：删除当前域名的网站级规则，并清理该域名对应的页面排除记录

删除类操作不会直接执行，均有明确的二次确认。

### 💻 页面 UI 控制面板

启用自动刷新后，网页右下角会出现控制面板：

* ⏱ 倒计时：显示真实剩余时间，并同步到浏览器标题栏
* 🏷 作用域：显示当前使用的是「网站范围」还是「精准网址」规则
* ⏸ 暂停：冻结真实剩余时间，继续后从暂停位置恢复
* ↻ 重置：重新按当前规则的完整间隔开始计时
* ⚙ 设置：打开统一设置 / 管理浮层
* 🖱 可拖拽：拖动面板顶部即可移动，位置会保存并自动限制在可视区域内

#### Mini Timer

完整面板闲置约 **5 秒**后会自动折叠：

```text
⏱ 00:04:33
```

暂停时显示：

```text
⏸ 00:04:33
```

Mini Timer 保持清晰可读，不再通过降低整个面板透明度来弱化存在感。悬浮、点击、键盘聚焦或触屏操作后会恢复完整面板；拖拽或设置浮层打开期间不会自动折叠。

### 📌 注意事项

* ✅ 最小刷新时间为 **1 秒**，只接受十进制整数；`0`、小数和宽松数字格式都会被拒绝
* ⚠️ **1–4 秒属于高频刷新**，设置浮层会要求再次确认；请确认目标网站允许此频率，避免增加服务器压力或触发限流 / 风控
* ✅ 精准网址规则优先于网站范围规则；停用当前页面不会误删整个网站规则
* ✅ 默认不生效，需你主动设置后才启用

### 🛠 技术信息

* 📦 技术栈：原生 JavaScript，无运行时依赖
* 🌐 通用匹配：`*://*/*`（可覆盖任意站点）
* 💾 配置：`GM_setValue` / `GM_getValue`，继续使用 v2 schema，并自动迁移旧版 `urlRefreshMap`
* ⏱ 计时：基于 `Date.now()` 的绝对 deadline，而不是简单每秒 `-1`
* 🎨 UI：Shadow DOM 隔离控制面板与设置浮层样式，拖拽位置自动 clamp 到当前视口
* ♿ 交互：设置浮层支持 Escape 关闭、键盘焦点管理与 `prefers-reduced-motion`
