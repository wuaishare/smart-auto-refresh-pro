# Smart Auto Refresh Pro v1.3.4 Quiet Start Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make every enabled page load directly into Mini Timer mode without flashing the expanded control panel.

**Architecture:** Keep the existing panel state machine and countdown logic. Change only the initial state/render path, restore saved position after Mini has its real dimensions, and retain existing click-to-expand plus idle-collapse behavior. Release as v1.3.4 and update README.

**Tech Stack:** Native JavaScript userscript, Node `node:test`, headless Google Chrome smoke harness.
