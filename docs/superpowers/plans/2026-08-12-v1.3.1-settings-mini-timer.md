# v1.3.1 Settings & Mini Timer Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the scattered v1.3 management commands and idle opacity fade with one accessible settings dialog and a compact Mini Timer, then release the verified result as v1.3.1.

**Architecture:** Keep `autoRefreshConfig_v2`, rule resolution, migration, and absolute deadline timing unchanged. Refactor management into pure config mutation helpers plus a Shadow DOM dialog, and refactor panel visibility into explicit `expanded` / `mini` UI state with a 5-second idle timer. Browser prompts remain only as a fallback if the custom dialog cannot be created.

**Tech Stack:** Vanilla JavaScript userscript, Shadow DOM, GM_* APIs, Node.js built-in `node:test`, headless Google Chrome smoke test.
