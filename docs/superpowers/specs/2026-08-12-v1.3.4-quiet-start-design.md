# Smart Auto Refresh Pro v1.3.4 Quiet Start Design

## Goal

When automatic refresh is enabled, every page load must start in Mini Timer mode instead of flashing the expanded control panel for five seconds.

## Behavior

- Initial panel mode is always `mini` when an active refresh rule exists.
- Mini Timer remains visible and readable immediately after page load.
- Hovering Mini does not expand it.
- Clicking Mini expands the full panel.
- An expanded panel still collapses back to Mini after about five seconds of inactivity.
- Opening settings forces the panel to expanded mode while settings are open.
- Existing pause/reset/settings, dragging, edge anchoring and countdown behavior remain unchanged.

## Position restoration

The saved panel position must be restored against the actual initial Mini dimensions. This avoids restoring an expanded-panel left coordinate and leaving a newly loaded Mini Timer unnecessarily far from the nearest edge.

The existing mode-switch edge-anchor logic continues to preserve the nearest viewport edge when switching between Mini and expanded modes within a page session.
