# v1.3.2 Interaction Polish Design

## Goal

修复 v1.3.1 中网站范围保存后当前页仍受精准规则覆盖的交互缺陷，并完善刷新间隔 Stepper、范围文案与 Mini Timer 拖拽/贴边体验。

## 1. 刷新间隔 Stepper

- 保留可直接输入的秒数。
- 输入区左右提供 `−` / `+` 按钮。
- 鼠标滚轮在 Stepper 上滚动时调整数值。
- 输入框聚焦时 `ArrowUp` / `ArrowDown` 调整数值。
- `Shift + 滚轮/方向键` 使用 10 秒步进，普通操作使用 1 秒步进。
- `−` 永远 clamp 到最小 1 秒。
- 按住 `−` / `+` 超过约 350ms 后连续调整，释放停止。
- 高频 1–4 秒仍沿用现有二次确认机制。

## 2. 刷新范围信息架构

将旧的“精准网址 / 网站范围”卡片改为更结果导向的名称：

- **仅当前页面**（标签：精准 URL）
  - 描述：只对当前完整网址生效；查询参数或地址变化后视为不同页面。
  - 显示当前完整 URL，长内容省略但保留 title。
- **整个网站**（标签：当前域名）
  - 描述：作为当前域名的默认刷新规则，站内页面继承；仍可为特定页面单独覆盖。
  - 显示当前 hostname。

## 3. 精准规则与网站规则冲突

当当前页已有精准规则、用户主动选择“整个网站”时：

- 默认选择“使用网站规则（推荐）”。
- 保存后删除当前页精准规则，使网站规则立即接管当前页。
- 另提供“保留当前页单独规则”作为高级选择，并明确说明当前页仍不会改变。
- `applyRuleUpdate()` 的底层默认也采用切换到 site 时移除当前 URL 精准规则，防止 UI 漏参再次造成静默覆盖。

## 4. Mini Timer 与拖拽

- Mini 状态 hover 不再自动展开。
- Mini 按钮本身同时作为拖拽手柄：
  - 按下后移动超过阈值才进入拖拽；
  - 未移动则视为点击并展开；
  - 拖拽结束不展开。
- 展开面板仍通过顶部 header 拖拽。
- 模式切换时按离当前视口最近的边缘保存锚点；靠右时保存 right gap，靠左时保存 left gap。
- 因此 Mini 右贴边后展开、收起都保持同一右边缘，不再因展开宽度 clamp 而向左漂移。
- resize 后继续按当前几何位置 clamp，保证不越界。

## 5. Validation

- Node 回归：保留现有规则/迁移/deadline 测试，新增 Stepper 数值 helper 与网站范围默认接管测试。
- Chrome HTTP smoke：验证 Stepper 点击/滚轮/键盘、范围卡片文案、冲突默认推荐项、网站规则保存意图，以及 Mini 不 hover 展开、Mini 可拖到右边缘、点击展开后保持右边缘。
- 发布前继续执行 `node --check`、`git diff --check`、canonical source scan。

## Version

v1.3.1 已发布，本次行为修复与 UX 完善作为 patch release 发布为 **v1.3.2**，确保 userscript 更新机制能够识别新版本。
