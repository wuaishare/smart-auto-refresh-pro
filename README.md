## 📄 网页自动刷新 Pro

> 每隔一段时间自动刷新网页，支持「网站范围」与「精准网址」两级规则、自定义刷新间隔、倒计时、暂停/重置、可拖拽控制面板与位置记忆。适用于挂机、心跳保持、PT站等使用场景，默认不启用，按需配置。

---

### 🚀 功能特点

* ✅ **网站范围 + 精准网址两级规则**：网站规则作为默认值，精准网址规则优先覆盖 (v1.3)
* ✅ **当前页面可单独关闭**：即使网站范围规则仍启用，也可通过精准网址排除当前页面 (v1.3)
* ✅ **绝对时间 deadline 计时**：修复旧版倒计时少 1 秒的问题，并降低后台标签页计时漂移 (v1.3)
* ✅ **支持 1 秒起的整数刷新间隔**：低于 5 秒时会再次确认高频刷新风险 (v1.3)
* ✅ **旧配置自动迁移**：兼容 v1.1 / v1.2 的 `urlRefreshMap`，迁移后仍保留旧数据 (v1.3)
* ✅ **面板样式隔离与边界保护**：使用 Shadow DOM 隔离大多数站点 CSS，并在窗口缩放后自动避免面板跑出可视区域 (v1.3)
* ✅ **右下角控制面板支持拖拽**，并会记住你拖动后的面板位置 (v1.2)
* ✅ **控制面板闲置后自动半透明**，悬浮、操作或键盘聚焦时恢复清晰 (v1.2 / v1.3 优化)
* ✅ 控制面板「⚙ 设置」可直接修改刷新规则
* ✅ 可手动暂停 / 继续刷新，并可一键重置倒计时
* ✅ 浏览器标题栏同步显示倒计时
* ✅ 所有设置持久保存，不用每次刷新都重新配置
* ✅ **默认不开启刷新**，仅在你主动设置后才运行

### 🧩 使用方法

#### 第一步：安装脚本

1. 点击页面上的【安装此脚本】按钮
2. 在你想启用自动刷新的网页打开后，点击浏览器右上角的油猴图标，找到本脚本名称

#### 第二步：设置刷新时间

* 点击脚本名称下的「🛠 设置当前页面刷新间隔」
* 输入刷新间隔，例如 `60`（表示每隔 60 秒刷新一次）
* 选择适用范围：
  * `1` 网站范围：当前域名下的页面默认使用此规则
  * `2` 精准网址：仅当前完整 URL 使用此规则，优先级高于网站规则
* 保存后脚本会自动刷新当前页面并立即应用新配置

#### 第三步：可选功能菜单

* 「❌ 关闭当前页面自动刷新」：保证当前精准网址停止刷新；若存在网站范围规则，只排除当前页面，不影响同域名的其他页面
* 「🗑 删除当前网站范围规则」：删除当前域名的网站级刷新规则，并清理该域名对应的页面排除记录

### 💻 页面UI控制面板

在启用自动刷新后，网页右下角会出现一个小面板，包含以下内容：

* ⏱ 倒计时：显示真实剩余时间，并同步到浏览器标题栏
* 🏷 作用域：明确显示当前使用的是「网站范围」还是「精准网址」规则
* ⏸ 暂停：冻结真实剩余时间，继续后从暂停位置恢复
* ↻ 重置：重新按当前规则的完整间隔开始计时
* ⚙ 设置：修改刷新间隔与适用范围
* 🖱 可拖拽：拖动面板顶部“拖动这里”即可移动，位置会保存并自动限制在可视区域内

---

### 📌 注意事项

* ✅ 最小刷新时间为 **1 秒**，只接受十进制整数；`0`、小数和宽松数字格式都会被拒绝
* ⚠️ **1–4 秒属于高频刷新**，脚本会二次确认；请确认目标网站允许此频率，避免增加服务器压力或触发限流/风控
* ✅ 精准网址规则优先于网站范围规则；关闭当前页面时不会误删整个网站规则
* ✅ 默认不生效，需你主动设置后才启用

### 🛠 技术信息

* 📦 技术栈：原生 JavaScript，无运行时依赖
* 🌐 通用匹配：`*://*/*`（可覆盖任意站点）
* 💾 配置：`GM_setValue` / `GM_getValue`，v1.3 使用版本化 v2 schema，并自动迁移旧版 `urlRefreshMap`
* ⏱ 计时：基于 `Date.now()` 的绝对 deadline，而不是简单每秒 `-1`
* 🎨 UI：Shadow DOM 隔离面板内部样式，拖拽位置自动 clamp 到当前视口
